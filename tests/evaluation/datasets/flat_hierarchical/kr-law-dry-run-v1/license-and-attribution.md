# 국가법령정보센터 데이터 출처 고지

- 제공 기관: 법제처 국가법령정보센터
- API: `https://www.law.go.kr/DRF/lawSearch.do`, `https://www.law.go.kr/DRF/lawService.do`
- 사용 범위: 현행 법령, 최근 연혁, 행정규칙 및 개발용 탐색적 판례
- 저장 정책: credential-bearing detail link를 제거한 source JSON과 정규화 스냅샷은 `local/evaluation-data/mba-279/`에만 저장

이 파일은 데이터 라이선스를 새로 부여하지 않는다. 실제 수집·배포·공유 시 국가법령정보센터의 당시 Open API 이용 조건과 공공데이터 출처 표시 기준을 다시 확인한다. 판례 트랙은 소수 사건의 선택 편향과 사실관계 길이 차이 때문에 확인적 결론이 아닌 탐색적 분석에만 사용한다.
