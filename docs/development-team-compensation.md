# Development Team Compensation Guide

## Purpose

이 문서는 개발팀의 연봉 밴드, 보상 기준, 조정 절차를 정리한다.

본 문서는 개인별 실제 연봉을 공개하지 않는다. 개인별 연봉, 계약 조건, 인센티브, 평가 결과는 HR 권한자와 본인만 접근할 수 있는 민감정보로 관리한다.

## Scope

적용 대상:

- Backend Engineer
- Frontend Engineer
- Full-stack Engineer
- DevOps / Platform Engineer
- AI / LLMOps Engineer
- Engineering Manager

적용 제외:

- 임원 보상
- 계약직, 프리랜서, 외주 인력 단가
- 개인별 성과급 산정 상세
- 채용 후보자의 개별 협상 조건

## Salary Band

단위는 연간 총 고정급 기준이며, 원화 KRW를 사용한다.

```text
L1 Junior Engineer
- 기준 경력: 0-2년
- 연봉 밴드: 40,000,000 - 55,000,000 KRW
- 기대 역할: 명확히 정의된 태스크를 독립적으로 구현하고 기본 테스트를 작성한다.

L2 Software Engineer
- 기준 경력: 2-5년
- 연봉 밴드: 55,000,000 - 75,000,000 KRW
- 기대 역할: 기능 단위 설계와 구현을 담당하고 코드 리뷰에 적극 참여한다.

L3 Senior Engineer
- 기준 경력: 5-8년
- 연봉 밴드: 75,000,000 - 100,000,000 KRW
- 기대 역할: 복잡한 기능, 장애 대응, 품질 기준 수립을 주도한다.

L4 Staff Engineer
- 기준 경력: 8년 이상
- 연봉 밴드: 100,000,000 - 130,000,000 KRW
- 기대 역할: 시스템 아키텍처, 기술 방향성, 팀 간 기술 조율을 책임진다.

L5 Principal Engineer
- 기준 경력: 10년 이상
- 연봉 밴드: 130,000,000 - 170,000,000 KRW
- 기대 역할: 회사 핵심 기술 전략과 장기 확장성, 보안, 운영 안정성을 책임진다.

Engineering Manager
- 기준 경력: 7년 이상
- 연봉 밴드: 95,000,000 - 150,000,000 KRW
- 기대 역할: 팀 목표, 인력 운영, 성과 관리, 채용, 실행 품질을 책임진다.
```

## Compensation Components

연간 보상은 다음 항목으로 구성될 수 있다.

- Base Salary: 고정 연봉
- Performance Bonus: 개인 및 조직 성과에 따른 성과급
- Retention Bonus: 핵심 인력 유지 목적의 일회성 보상
- Equity / Stock Option: 회사 정책에 따른 장기 인센티브
- Allowance: 식대, 통신비, 교육비, 장비 지원 등 복리후생성 지원

## Level Decision Criteria

레벨은 단순 경력 연차가 아니라 실제 영향 범위로 판단한다.

평가 기준:

- 문제 정의 능력
- 구현 품질
- 코드 리뷰 품질
- 장애 예방 및 대응 능력
- 보안과 개인정보 보호 기준 준수
- 문서화와 지식 공유
- 제품과 고객 영향 이해도
- 다른 구성원 성장에 대한 기여

## Salary Adjustment

연봉 조정은 원칙적으로 연 1회 진행한다.

예외적으로 다음 경우에는 수시 조정을 검토할 수 있다.

- 승진
- 역할 범위의 급격한 확대
- 핵심 인력 유지 필요
- 시장 보상 수준과의 큰 괴리
- 조직 개편으로 인한 책임 변경

## Promotion And Salary Change

승진과 연봉 조정은 항상 동시에 발생하지 않을 수 있다.

```text
승진 있음 + 연봉 조정 있음:
- 역할과 보상 모두 변경되는 일반적인 승진 케이스

승진 있음 + 연봉 조정 없음:
- 이미 상위 밴드에 가까운 보상을 받고 있는 경우

승진 없음 + 연봉 조정 있음:
- 시장 보상 보정 또는 성과 반영

승진 없음 + 연봉 조정 없음:
- 현재 역할과 보상 수준 유지
```

## Confidentiality

다음 정보는 공개 문서, Slack 공개 채널, Git repository, 티켓, 로그에 남기지 않는다.

- 개인별 실제 연봉
- 개인별 성과급
- 개인별 평가 등급
- 계약서 원문
- 계좌 정보
- 주민등록번호 등 고유식별정보
- 채용 후보자의 개별 제안 금액

연봉 관련 문서를 저장할 때는 접근 권한을 HR, 경영진, 직속 리더 등 필요한 인원으로 제한한다.

## Example Usage

채용 공고에는 세부 개인 보상 대신 레벨별 범위 또는 협의 가능 범위를 사용한다.

```text
예시:
Senior Backend Engineer
- 예상 레벨: L3
- 연봉 범위: 75,000,000 - 100,000,000 KRW
- 최종 처우는 인터뷰 결과와 역할 범위에 따라 결정
```

내부 승진 검토에는 개인별 연봉 대신 현재 레벨, 후보 레벨, 밴드 위치를 사용한다.

```text
예시:
- 현재 레벨: L2
- 후보 레벨: L3
- 현재 보상 위치: L2 상단
- 검토 방향: L3 하단 진입 또는 6개월 후 재평가
```

## Review Cycle

이 문서는 최소 연 1회 검토한다.

검토 시 확인 항목:

- 시장 연봉 변화
- 채용 경쟁력
- 내부 형평성
- 역할별 책임 변화
- 회사 재무 상황
- 조직 성장 단계
