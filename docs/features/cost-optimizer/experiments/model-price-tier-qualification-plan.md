# 모델 가격군 대표 선발 및 80건 재검증

Status: Draft

## 목적

시스템 전체 일반 텍스트 workflow 후보를 가격 기준으로 저가·중가·고가군에 나눈다. 각 군에서 별도 16건 예선으로 품질 하한을 지키는 가장 싼 대표를 선발한 뒤, 대표 3종과 전체 후보 자동 라우팅을 기존 80건 데이터셋으로 다시 비교한다.

기존 6개 후보 실험의 `고가`·`중가`·`저가`는 제한된 후보 안의 상대 등급이었다. 이번 실험은 현재 실행 주체가 실제 사용할 수 있고 workflow chat 필터를 통과한 비버전 모델을 시작점으로 삼는다.

## 가격군

요청당 가격 비교 기준은 입력 4K token과 출력 1K token이다.

- 저가: 기준 요청 비용이 `$0.0032` 이하
- 중가: `$0.0032` 초과 `$0.025` 이하
- 고가: `$0.025` 초과이며 `-pro`가 아닌 모델
- 초고가 관찰군: `-pro` 모델. 기본 예선과 자동 라우팅 후보에서 제외한다.

가격이 없거나 credential `use` 권한, active chat model, verified credential 조건을 만족하지 않는 모델은 예선에 포함하지 않는다. image, audio, realtime, embedding, moderation, search, dated version 모델은 기존 workflow chat 필터로 제외한다.

## 별도 16건 예선

최종 80건과 문장이 겹치지 않는 synthetic 요청 16건을 사용한다.

- 입력 구조 `flat_text`, `nested_ticket`, `conversation`, `batch_record`: 각 4건
- 입력 길이 `short`, `medium`, `long`, `very_long`: 각 4건
- 난이도 `economy`, `balanced`, `advanced` 포함
- 업무 영역 8종 이상

각 모델은 동일 workflow와 JSON 출력 계약으로 16건을 모두 실행한다. 품질 Judge는 모델명, 가격, latency, 실행 순서를 보지 않고 최대 5개 출력을 한 묶음으로 평가한다.

## 대표 선발 gate

각 가격군에서 다음 순서로 대표를 고른다.

1. 16건을 모두 시도한다.
2. workflow 성공률과 JSON schema 통과율이 각각 90% 이상이어야 한다.
3. 품질 계약 통과율이 80% 이상이어야 한다.
4. 위 조건을 통과한 모델 중 최고 평균 품질의 3점 이내 후보만 남긴다.
5. 남은 후보 중 실제 평균 비용이 가장 낮은 모델을 대표로 선택한다. 비용이 같으면 latency가 낮은 모델을 선택한다.

대표를 고를 수 없는 가격군이 있으면 최종 80건 실행을 시작하지 않는다.

## 최종 4-arm 재검증

- `high_fixed`: 고가군 대표
- `mid_fixed`: 중가군 대표
- `low_fixed`: 저가군 대표
- `automatic`: 초고가 관찰군을 제외한 예선 대상 전체 모델

최종 데이터셋, blind Judge 계약, 비용·품질·시간·심각 회귀 trade-off gate는 `judge-first-economics-80-four-arm-plan.md`를 그대로 사용한다. 예선 비용과 최종 제품 실행 비용, 품질 Judge 비용은 각각 분리해 보고한다.

## 2026-07-18 실행 결과

실행 시점의 workflow chat 후보 19종을 가격으로 나눈 뒤, 초고가 관찰군 2종을 제외한 17종을 예선과 자동 라우팅 후보로 사용했다.

- 저가군 5종: `gpt-5-nano`, `gpt-4o-mini`, `gpt-5.4-nano`, `gpt-5-mini`, `gpt-4.1-mini`
- 중가군 10종: `gpt-5.4-mini`, `gpt-5.6-luna`, `gpt-5`, `gpt-5.1`, `gpt-4.1`, `o3`, `gpt-4o`, `gpt-5.2`, `gpt-5.4`, `gpt-5.6-terra`
- 고가군 2종: `gpt-5.5`, `gpt-5.6-sol`
- 초고가 관찰군 2종: `gpt-5.4-pro`, `gpt-5.5-pro`

16건 예선은 모델 실행 272회와 blind 품질 Judge 64회로 완료했다. 선발 gate를 통과한 대표는 저가 `gpt-5-mini`, 중가 `gpt-5.6-luna`, 고가 `gpt-5.6-sol`이다. 예선 모델 실행 비용은 `$1.775866`, 품질 Judge 비용은 `$0.122494`였다.

선발 대표 3종과 17종 자동 라우팅으로 최종 80건을 실행한 결과는 다음과 같다.

| arm | 총 제품 비용 | 평균 전체 시간 | 평균 품질 | workflow 성공 | 품질 통과 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 자동 라우팅 | $0.166852 | 7335ms | 69.26 | 100.0% | 23.8% |
| 고가 고정 | $1.581290 | 16014ms | 87.54 | 100.0% | 96.2% |
| 중가 고정 | $0.272854 | 4725ms | 84.46 | 100.0% | 93.8% |
| 저가 고정 | $0.123488 | 8190ms | 88.38 | 97.5% | 95.0% |

자동 라우팅은 고가 고정 대비 `$1.414438`, 89.4%를 절감했지만 평균 품질이 18.27점 낮았고 80건 중 73건에서 10점 이상 하락했다. 자동 라우팅은 77건을 `gpt-4.1-mini`로 보냈으며, 저가 고정보다도 `$0.043364` 비싸면서 평균 품질은 19.11점 낮았다. 따라서 현재 Runtime Judge 선택 규칙의 trade-off는 합리적이지 않다. 다음 반복에서는 예선 품질 gate를 자동 후보에도 적용하고, 품질 계약을 라우팅 프롬프트와 선택 점수에 직접 반영해야 한다.

최종 80건의 독립 품질 Judge 비용은 `$0.147183`이며 제품 운영비 비교에서는 제외했다. 품질 점수는 LLM Judge의 대리 지표이므로 운영 적용 전 사람 검수와 실제 업무 실패 비용 확인이 필요하다.
