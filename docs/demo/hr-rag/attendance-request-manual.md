# 근태 신청 매뉴얼

## 1. HR 포털 접속

휴가 및 근태 신청은 사내 HR 포털에서 진행한다.

접속 경로는 다음과 같다.

```text
HR 포털 > 근태/휴가 > 휴가 신청
```

임직원은 HR 포털에 로그인한 뒤 본인에게 필요한 휴가 유형을 선택해 신청서를 작성한다.

## 2. 휴가 신청 방법

휴가 신청 절차는 다음과 같다.

1. HR 포털에 로그인한다.
2. 상단 메뉴에서 근태/휴가를 선택한다.
3. 휴가 신청 버튼을 클릭한다.
4. 휴가 유형을 선택한다.
5. 휴가 시작일과 종료일을 입력한다.
6. 신청 사유를 작성한다.
7. 필요한 경우 증빙자료를 첨부한다.
8. 신청 버튼을 클릭한다.

신청 후 승인 상태는 HR 포털의 신청 내역 화면에서 확인할 수 있다.

## 3. 휴가 유형 선택 기준

연차를 사용하는 경우 휴가 유형에서 `연차`를 선택한다.

가족 돌봄 사유가 있는 경우 휴가 유형에서 `가족돌봄휴가`를 선택한다.

병원 진료, 입원 동행, 가족 질병 돌봄 등은 가족돌봄휴가 사유에 해당할 수 있다.

## 4. 여러 휴가를 이어서 사용하는 경우

서로 다른 휴가 유형을 이어서 사용하는 경우 각 휴가를 별도로 신청해야 한다.

예시는 다음과 같다.

- 7월 6일 ~ 7월 8일: 가족돌봄휴가
- 7월 9일 ~ 7월 10일: 연차

위와 같은 경우 가족돌봄휴가 신청 1건, 연차 신청 1건을 각각 등록해야 한다.

## 5. 승인 확인

신청한 휴가는 팀장 승인 후 근태 캘린더에 반영된다.

승인 상태는 다음 경로에서 확인할 수 있다.

```text
HR 포털 > 근태/휴가 > 신청 내역
```

승인이 반려된 경우 반려 사유를 확인한 뒤 내용을 수정해 다시 신청할 수 있다.
